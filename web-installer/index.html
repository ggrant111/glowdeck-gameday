3-step guided setup

Factory flashing may erase your settings. The combined image includes the partition table and writes blank padding across saved NVS settings. This installer is meant for a new or intentionally reset device. If GameDay is already working, use Device → Firmware & Maintenance on its local dashboard with the board's -ota.bin release asset instead.
  1. Install firmware: Connect your original CYD or Waveshare S3 3.5 via a USB data cable to desktop Chrome/Edge. Click Connect & install, select its serial port and confirm the factory-flash prompt.
  2. Connect home Wi-Fi: Leave the USB cable plugged in after the board reboots. ESP Web Tools should automatically display its Configure Wi-Fi step. Select or enter the 2.4 GHz Wi-Fi name and password, then connect. The device saves the credentials only after successfully joining your network.
  3. Open GameDay: On successful Wi-Fi connection, use the Visit device link in ESP Web Tools to finish configuration and choose your NHL games, lighting and audio settings.

Wi-Fi setup uses the open Improv Serial protocol over USB. Neither your Wi-Fi password nor setup data is sent to the GitHub Pages website; the browser transfers it directly to your connected ESP32. This requires the latest GameDay firmware with Improv enabled.

This browser does not support Web Serial. Open this page in desktop Chrome or Edge with the ESP32 plugged in via USB. iOS browsers cannot flash it.

Browser serial access requires HTTPS and a secure context. Open the published GitHub Pages installer URL.

Installing requires a physical USB connection to the ESP32 on this computer. It cannot flash a remote ESP32 or directly flash through an iPhone.

No USB Wi-Fi prompt? Use the on-screen QR code.

Whenever GameDay has no working home Wi-Fi connection, its SETUP screen displays a QR code for the password-protected GlowDeck-XXXXXX hotspot. Scan it with your phone camera, accept the phone's Join Wi-Fi prompt, then browse to http://192.168.4.1 to enter your home Wi-Fi credentials.

The QR code joins the ESP32's hotspot, not your home router. Phones require confirmation before joining a network; they cannot be forced to connect silently. This recovery path also works later if the home Wi-Fi password changes.

Already running GameDay?

Use the board's authenticated local web dashboard for an OTA update to preserve its NVS settings and S3 LittleFS sound files, provided you are not changing its partition layout. Get the -ota.bin matching your exact model from the GitHub release.
